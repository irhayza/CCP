Letakkan file font STATIS (.ttf / .otf) di folder ini, mis. Montserrat-ExtraBold.ttf, Poppins-Bold.ttf.

Unduh gratis (lisensi OFL) dari https://fonts.google.com. Pilih berkas "static", bukan variable font:
libass (mesin caption ffmpeg) tidak andal membaca variable font.

Nama keluarga font harus sama dengan yang dipilih di Studio (Outfit, Montserrat, Poppins, Roboto, Inter,
Bebas Neue, Anton, Impact). Jika font tidak ada, ffmpeg memakai font sistem sebagai cadangan.
